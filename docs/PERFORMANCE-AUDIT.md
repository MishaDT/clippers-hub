# ReelPay — второй проход производительности

## Выполнено

- Пять основных PNG заменены на WebP: общий вес уменьшен примерно с 8,7 МБ до 272 КБ.
- Превью лендинга, ленты, лидерборда и Open Graph используют облегчённые файлы.
- Canvas-анимации лидерборда полностью останавливаются вне экрана и в скрытой вкладке.
- `prefers-reduced-motion` получает статичный кадр вместо постоянной перерисовки.
- Обработчик клавиатуры ленты больше не пересоздаётся после каждого рендера.
- Аватары в ленте загружаются лениво и декодируются асинхронно.
- Независимые запросы настроек профиля и подключённых площадок выполняются параллельно.

## Следующий безопасный этап

1. Разделить `globals.css` по маршрутам. Сейчас исходный файл около 497 КБ; слепое удаление запрещено из-за старых зависимостей классов.
2. Перенести стили кошелька, лидерборда, чатов и админки в CSS Modules по одному экрану за проход.
3. После каждого переноса проверять 320/360/375/390/768/1440 px и сравнивать CSS-чанк production-сборки.
4. Заменять оставшиеся внешние `<img>` на оптимизированный прокси только после настройки разрешённых доменов и защиты от SSRF.
5. Добавить staging Lighthouse и Web Vitals-бюджеты в CI: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.

## Ограничения

- Большие исходные PNG пока сохранены в репозитории как резерв, но браузер их больше не загружает.
- `globals.css` нельзя автоматически чистить PurgeCSS: часть классов строится динамически и используется серверными страницами.
